Material Design 3 · brand-led skin

One system for the website, the crew portal and every operational app.

Rescue MD3 takes Material Design 3’s component semantics, colour roles and layout model and skins them in the group’s own identity: marine navy as the working ground, rescue orange reserved as a signal. It is written to be read by people and by coding agents, and every value resolves to one token file.

Principles

Four rules that settle most arguments

visibility
Legible before beautiful

Read on a phone in sunlight, on a bridge at night, by a volunteer of any age. Size, contrast and target area win over refinement.

emergency
Orange means act

Rescue orange is a signal, not a brand flood. If it appears twice on a screen for two different reasons, one of them is wrong.

rule
One token file

Colour, type, spacing, shape, elevation and motion all resolve to tokens.dtcg.json. A hard-coded hex is a defect.

layers
Same parts, three voices

Public pages breathe, the intranet is comfortable, operational apps are dense. Same components, different spacing steps — never different components.

Foundations

Motion

Motion confirms, it never decorates. Four durations, one standard easing curve. Nothing on an operational screen moves unless the data changed or the user acted — and reduced-motion preferences disable all of it.

100ms short
Hover, focus, ripple, checkbox.
200ms medium
Menus, snackbars, chip selection.
350ms long
Dialogs, drawers, page transitions.
500ms extra long
Distress pulse only.

Rules for agents

Paste this section, or AGENTS.md, into the working context of any coding agent building on this system.

01
Read tokens.dtcg.json first. No literal hex, font name, radius or spacing value in application code.
02
Light scheme for public and intranet, dark scheme for operational and night surfaces. Never a third scheme.
03
One filled button per view. Emergency actions are tertiary at 48px with an icon. Destructive actions are outlined error, confirmed by a dialog.
04
Status comes from the seven-value set only, as colour plus icon plus label. Extend the vocabulary in tokens.dtcg.json or not at all.
05
Targets 48px minimum, inputs 56px, body text 14px minimum in applications and 16px on the public site.
06
Material Symbols Rounded only. No second icon set, no hand-drawn SVG icons.
07
Every screen ships its empty, loading and error state. An improvised blank screen is an unfinished screen.
08
Copy is plain and calm: sentence case, 24-hour time, Australian spelling, no exclamation marks in operational UI.
09
Keyboard focus is a 2px primary ring at 2px offset on every interactive element. Never remove an outline without replacing it.
10
If a component you need is not documented here, compose it from Material 3 primitives and these tokens — then add it to this page.
